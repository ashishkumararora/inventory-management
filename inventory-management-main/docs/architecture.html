API Endpoints server/main.py · base: /api

GET /inventory All stock items — filters: warehouse, category
GET /inventory/{id} Single item detail
GET /orders Order list — filters: warehouse, category, status, month (YYYY-MM or Q#-YYYY)
GET /orders/{id} Single order detail
GET /dashboard/summary KPI aggregates — all 4 filters supported; revenue goal $800K/mo · $9.6M YTD
GET /demand Demand forecasts — no filters
GET /backlog Backlog items with purchase order status — no filters
GET /spending/summary|monthly|categories|transactions Financial data by slice
GET /reports/quarterly Quarterly KPIs: revenue, fulfillment rate, avg order value
GET /reports/monthly-trends Month-over-month trends
POST /purchase-orders Create purchase order from backlog item
GET /purchase-orders/{backlog_item_id} Look up PO by backlog item
